# Evolution Tracker (Living Chronicle)

Purpose: Track the growth of the app across sprints and releases, beyond code diffs. Captures functional progress, decisions, and performance.

## How to Use
- Add an entry per sprint or release.
- Include highlights, completed/in-progress items, performance snapshots, decisions, and links to PRs.
- Keep short and factual; link to detailed docs.

- Period: YYYY-MM-DD → YYYY-MM-DD

  - ...
- In Progress:
  - ...
- Performance Snapshot (resolution, steps, frame time):
  - ...
- Decisions & Changes:
  - ...
- References (PRs/issues/docs):
  - ...
